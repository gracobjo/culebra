# Marco de documentación del expediente

**Proyecto:** Marketplace de productos de la Sierra de la Culebra (*Sabores de la Culebra*)  
**Sede:** Villardeciervos (Zamora)  
**Destinatarios institucionales:** ICECYL, Diputación de Zamora, socios

Este documento fija **qué tipo de memoria corresponde en cada fase**, qué pregunta responde cada una y cómo se relacionan entre sí. Evita duplicar contenido y, sobre todo, evita presentar como justificación lo que aún es previsión.

---

## 1. La diferencia en una frase

> **La Memoria de Proyecto explica qué queremos hacer, por qué tiene sentido y qué resultados esperamos conseguir.**

> **La Memoria Técnica Justificativa demuestra que lo que hemos hecho, comprado y gastado corresponde realmente al proyecto subvencionado y cumple las condiciones de la ayuda.**

| Uso principal | Documento |
|---------------|-----------|
| Obtener / apoyar la decisión de inversión o subvención | Memoria de Proyecto |
| Justificar la ejecución y cobrar / consolidar la subvención | Memoria Técnica Justificativa |

---

## 2. Comparación directa

| | Memoria de Proyecto | Memoria Técnica Justificativa |
|---|---------------------|-------------------------------|
| **Momento** | Antes de ejecutar | Después / durante la ejecución |
| **Finalidad** | Convencer y demostrar viabilidad | Demostrar cumplimiento |
| **Pregunta principal** | **¿Qué vamos a hacer y por qué?** | **¿Qué hemos hecho y cómo lo demostramos?** |
| **Destinatario** | ICECYL, Diputación, socios, inversores | Administración concedente |
| **Datos** | Previsiones + datos oficiales | Datos reales y verificables |
| **Presupuesto** | Previsto | Ejecutado |
| **Inversiones** | Previstas | Realizadas |
| **Facturas** | No necesariamente | Sí |
| **Contratos** | Propuestos | Ejecutados |
| **Indicadores** | Objetivos | Resultados |
| **Empleo** | Previsto | Creado / mantenido y acreditado |
| **Plataforma** | Diseño y funcionalidades previstas | Plataforma realmente desarrollada |
| **Proveedores** | Necesidades de contratación | Contratos, facturas y pagos |
| **Subvención** | Solicitud | Justificación |
| **Confidencialidad** | Puede ser pública / institucional | Solo lo necesario para acreditar el gasto |

**Regla de redacción:** en la Memoria de Proyecto se habla de **objetivos**; en la justificativa, de **resultados** demostrables.

## 3. Tres documentos, no dos

Para un expediente con subvención pública conviene trabajar con **tres piezas**:

```text
                    PROYECTO
                       │
                       ▼
             MEMORIA DE PROYECTO
                       │
          ┌────────────┼────────────┐
          ▼            ▼            ▼
       ICECYL      DIPUTACIÓN     SOCIOS
          │
          ▼
      CONCESIÓN
          │
          ▼
    EJECUCIÓN DEL PROYECTO
          │
          ▼
 MEMORIA TÉCNICA DE EJECUCIÓN
   (Cuaderno de Ejecución y Justificación)
          │
   ┌──────┼───────┐
   ▼      ▼       ▼
Contratos Facturas Pagos
   │      │       │
   └──────┼───────┘
          ▼
 MEMORIA TÉCNICA JUSTIFICATIVA
          │
          ▼
       JUSTIFICACIÓN
```

**No convertir** la Memoria de Proyecto en una justificativa. Mantener tonos distintos:

- *Proyecto:* «La plataforma pretende convertirse en una infraestructura digital de referencia para la comercialización de productos de la Sierra de la Culebra.»
- *Justificativa:* «Durante el periodo comprendido entre X y X se ejecutó el desarrollo de los módulos A, B, C y D, conforme al contrato de fecha X. La inversión ascendió a X euros, IVA excluido, y fue abonada mediante transferencia bancaria en fecha X.»

2. Quién lo va a crear

## 5. Desarrollo tecnológico: formulación recomendada

**No** construir el expediente alrededor de «un técnico DAW» como figura imprescindible y necesariamente contratada por la empresa.

**Formulación estándar** (Memoria de Proyecto y descripción técnica):

> El desarrollo tecnológico podrá ejecutarse mediante recursos internos, contratación de personal especializado y/o contratación de servicios tecnológicos externos especializados, en función de las necesidades técnicas y de la fase de ejecución del proyecto.

**Modelo organizativo:**

```text
                    EMPRESA
                       │
             Dirección del proyecto
                       │
        ┌──────────────┼──────────────┐
        ▼              ▼              ▼
   Desarrollo       Seguridad      Servicios
   tecnológico      y RGPD        especializados
        │
        ▼
 Empresa tecnológica
 especializada (si procede)
```

Capacidades necesarias (sin vincularlas a un único perfil):

- desarrollo web y mantenimiento;
- comercio electrónico;
- marketing;
- RGPD;
- operaciones;
- relación con productores;
- gestión financiera.

## 7. Matriz ampliada de justificación

La matriz del borrador técnico conecta inversión, necesidad, resultado e indicador. Para el cuaderno de ejecución se amplía a:

> **Partida → proveedor → contrato → inversión → necesidad → entregable → indicador → factura → pago → evidencia → impacto → subvención**

Esto convierte la documentación en **herramienta de control**, no solo en un texto que se redacta al final del proyecto.

1. Presentar y mantener actualizada la **Memoria de Proyecto** para solicitudes y alianzas.
